# Frontend Web Development Projects

## Overview

This repository contains a collection of **frontend web development projects** built using **HTML, CSS, and JavaScript**.  
The goal of these projects is to strengthen core frontend concepts such as layout design, responsive UI, styling, and basic interactivity.

These projects are inspired by real-world platforms and are created purely for **learning and practice purposes**.

---

## Projects Included

### 1. Amazon Clone
A static clone of the Amazon homepage designed to replicate the layout, navigation, and visual structure.

**Key Features:**
- Header with search bar and navigation links  
- Product listing sections  
- Responsive layout using CSS  
- Clean and structured HTML  

---

### 2. Netflix Clone
A frontend recreation of Netflix’s homepage focusing on UI and layout design.

**Key Features:**
- Hero banner section  
- Movie/show cards layout  
- Hover effects and styling  
- Responsive design for different screen sizes  

---

### 3. Spotify Clone
A music player interface inspired by Spotify’s web UI.

**Key Features:**
- Sidebar navigation layout  
- Music player controls (UI-based)  
- Playlist and album sections  
- Modern styling using CSS  

---

## Technologies Used

- **HTML5** – Structure and layout  
- **CSS3** – Styling, layout, responsiveness  
- **JavaScript** – Basic interactivity and DOM manipulation

## How to Run the Projects

1. Clone or download the repository  
2. Open any project folder  
3. Open `index.html` in your browser  

No additional setup or dependencies required.
